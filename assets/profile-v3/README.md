# 紧凑作品页素材

封面由 `motion/profile-opening` 的独立 Remotion 合成渲染，保留完整短开场与居中字标，完全删除 3D 头像卡片。动画是 96 帧、30fps，播放一次，末帧永久保持完整字标。原个人站没有改动。

- `opening.webp`：1200 × 480，约 0.86 MB。
- `opening-mobile.webp`：810 × 480，约 0.73 MB。
- 手机静态封面位于本目录；桌面静态封面位于 `assets/profile-v2/opening-poster.webp`。
- SVG 使用 Playfair Display 与 Noto Sans CJK SC 的路径字形，延续原站字体、纸色与轻颗粒；移除黑橙大色块与重复的大号双栏区块。
- Pi 作品图来自原有真实截图 `assets/profile/pi-desktop.png`，用 SVG viewBox 裁去桌面外框；它是静态界面，不是录屏或推镜。

四个辅助项目使用紧凑索引，全部链接真实仓库。可展开的文字版保留完整介绍，支持复制和辅助阅读。
